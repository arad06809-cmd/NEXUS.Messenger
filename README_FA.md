# NEXUS — بسته چندفایلی برای Runflare

این بسته نسخه فعلی NEXO را به ساختار چندفایلی منتقل می‌کند. APIها و منطق فعلی حفظ شده‌اند و دو رابط HTML از فایل پایتون جدا شده‌اند.

## ساختار
- `app.py`: ورودی WSGI
- `backend/core.py`: منطق فعلی Flask، APIها، احراز هویت و SQLite
- `templates/client.html`: رابط کاربری
- `templates/admin.html`: پنل مدیریت
- `static/`: محل فایل‌های استاتیک
- `uploads/`, `backups/`, `instance/`: داده‌های runtime

## استقرار
1. ZIP را در بخش افزودن سورس سرویس Runflare بارگذاری کنید.
2. وابستگی‌ها: `pip install -r requirements.txt`
3. دستور اجرا: `gunicorn --worker-class gthread --threads 100 --workers 1 --bind 0.0.0.0:$PORT app:app`
4. متغیر محیطی `NEXO_SECRET_KEY` را با یک کلید تصادفی طولانی و محرمانه تنظیم کنید.
5. برای AI، مقدار `NEXO_OPENROUTER_KEY` را در تنظیم متغیرهای محیطی قرار دهید؛ کلید را داخل فایل کد ننویسید.
6. مسیر دیتابیس و پوشه‌های `uploads/`, `backups/`, `instance/` باید روی دیسک دائمی/Volume قرار بگیرند. کانتینر موقت برای نگهداری SQLite مناسب نیست.

## اجرای محلی
```bash
pip install -r requirements.txt
python run.py
```
سپس آدرس `http://127.0.0.1:5000` و پنل مدیریت `/admin` است.

## وضعیت واقعی قابلیت‌ها
این بسته انتقال ساختاری نسخه قبلی است، نه بازنویسی کامل یا ممیزی امنیتی. پیش از انتشار عمومی باید مجوزهای API، مدیریت مدیر اولیه، CSRF، نشست‌ها، محدودسازی درخواست، آپلود فایل و بازیابی بکاپ بررسی و تست شوند. SQLite فقط با فضای دائمی و یک نمونه نویسنده قابل اتکاست. تماس صوتی/تصویری و تبلیغات تصویری در این نسخه قابلیت کامل محسوب نمی‌شوند و باید در مراحل بعدی پیاده‌سازی و تست شوند.
